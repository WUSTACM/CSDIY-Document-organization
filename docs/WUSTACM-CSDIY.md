# WUSTACM CSDIY组路线（开发组）

**本组面向所有年级招新**

## 1 关于我们

我先从大家可能比较关心的**学什么? 有什么用? 要求是什么**这几个问题介绍下

### 1.1 我们在学什么？

我们组叫做`csdiy`组，因为我们的全部学习内容来自于一位北大信计学长开启的一份开源自学指南， 而后经过全国各地的学生们共同参与维护的开源课程汇总，最终形成现在的——[CSDIY](https://csdiy.wiki)

里面的课程是收集于全世界各地~~哈佛，斯坦福，卡内基梅隆，麻烦理工等等~~的最优质大学的开源课程和资源。大部分课程都不仅有完整教学视频，更重要的是有质量极高的作业。并且许多课程都在实时更新。紧跟时代的变化。

### 1.2 学这些有什么用？

公认最顶尖的课程。。。对于双非学校，能接受到的教育资源难免有限，接触开源课程恰恰是计算机专业的优势。真正学明白这些开源课程，再面对学校的课程必然势如破竹（bushi

在学习过程中，你也自然会使用到各种实用的工具，如`git`，`markdown`，`github`，`LaTex`，`GNU`，`gdb`等等......真正培养自己的专业素养专业能力。

并且之中有不少课程中有许多质量不错的`project`。有的甚至可以写入简历当中。无论是求职或者是升学都会有帮助😋

### 1.3 入组的要求是什么？

首先需要区分我们组和普通俱乐部的区别。我们希望维护出一个属于武科大的`CSDIY`学习社区。自然希望投入这个社区学习和维护的人越多越好！但工位是有限的，所以我们只能分出核心成员和普通成员。我们会开源出所有我们的学习产出[WUST开源学习文档](https://csdiy.wustacm.com)，同时会组建一个交流群。当然，也欢迎所有成员投稿发布自己的学习所得和避坑指南。

所以，对于普通成员入组，只要愿意投入时间学习`CSDIY`即可，没有其他要求，但群聊基本管控会有，大家遵守即可。
而核心成员选拔，会参考大家的学习进度以及文档产出，最后安排面试进行统一选拔。

## 2 正文（学习路线

以下是我们的参考路线，也是我个人的学习路线。之中在对应课程的学习之前，请先在我们的[经验文档](https://csdiy.wustacm.com)中找到对应课程的博文，里面有我们留下的对应课程的一些心得和避坑指南。会有帮助。如在过程中仍然遇到问题，可以在交流群中提出。

### 2.1 基本代码能力

所有人在开始`CSDIY`学习之前，请先保证自己有基本的代码能力。顶尖学校的零基础课程对我们的零基础未必合适。这也是我们的学习真实感受。

**如何判断自己是否有基本的代码能力呢**刷`oj`题单，如果你是老生，之前有完成过`oj`的c语言题单，可以直接跳过这步。否则请先完成[WUSTACM招新入门题单](https://blog.wustacm.com/2026/wustacm-newcomer-guide)
