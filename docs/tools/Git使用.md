# Git使用

## 使用git创建和修改本地仓库

1. 新建一个空文件夹

2. 在空文件夹点击右键，然后点击Open Git Bash here打开git终端

3. 初始化

   ```
   git init
   ```

   这样就会新建一个.git文件夹，生成本地仓库

4. 完成修改操作，包括增加、删除、修改文件

5. 将工作区的内容添加到暂存区

   ```
   git add test.txt
   ```

   这里的test.txt是文件名

6. 如果想要把暂存区的内容移动到工作区

   ```
   git rm --cached test.txt
   ```

7. 将暂存区的内容添加到仓库当中

   ```
   git commit -m 新增文件
   ```

   -m 表示消息，后面接着commit操作携带的消息

8. 查看提交信息

   ```
   git log
   ```

   查看所有提交日志

   可添加--oneline就可以在一行显示，避免看起来太乱

   ```
   git log --oneline
   ```

   查看某一次提交之前的提交

   ```
   git long --oneline 提交版本号
   ```

9. 误删除恢复操作

   * 如果误删除了一个文件，在删除操作**还没有commit**的情况下，可以直接恢复

   ```
   git restore text.txt
   ```

   ​	即可恢复刚才删除的text.txt

   ​	会将存储区里的text.txt恢复到工作区

   * 如果是删除了，并将删除操作**已经commit**的情况下，也可以恢复

     先得到提交日志，找到之前**提交**该被删除文件的**操作**，复制其版本号

   ```
   git log --oneline
   ```

   ​	然后

   ```
   git reset --hard 79378a4
   ```

   ​	这里的79378a4为**版本号**，要根据实际情况填写

   ​	这样操作的实质是**版本回退**，会删除刚才删除该文件的操作的提交日志

   + **最好的**恢复方法

     注意这里针对的还是已经提交commit的情况

   ```
   git revert e6cd120
   ```

   ​	这里的e6cd120是刚才删除操作的版本号

   ​	这一步实际上会创建一个新的提交commit，一样可以实现恢复操作

   ​	优点是不会删除提交日志

10. 分支操作

    1. 创建新的分支

       ```
       git branch user
       ```

       创建一个名为user的分支

       注意：要先有至少一个提交才可以创建分支

    2. 切换到新的分支

       ```
       git checkout user
       ```

       切换到user分支

    3. 创建新的分支并切换过去（两步合成一步）

       ```
       git checkout -b order
       ```

       创建了一个新的分支名叫order并切换过去了

    4. 删除分支

       ```
       git branch -d user
       ```

       将分支user删除

    5. 合并分支

       ```
       git merge order
       ```

       如果此时在master分支，就会将order分支内的文件合并到master分支内

    6. 合并冲突

       如果两个分支内有同名的文件，将会造成冲突，需要人为解决

       解决办法是手动修改master（当前分支）内的同名文件，改成需要的

11. 标签操作

    1. 设置标签

       ```
       git tag _name 版本号
       ```

       其中_name为版本号的别名

       标签不能重复

    2. 删除标签

       ```
       git tag -d _name
       ```

       删除名为_name的标签

    3. 通过标签创建分支

       ```
       git checkout -b addfile
       ```

       创建一个名叫addfile的分支，而这个分支实际上是一个标签

## 使用git管理远程仓库

1. 同样在文件夹里先打开git终端

2. 输入命令

   ```
   git clone 网址
   ```

   **网址**为想要下载的仓库的网址，对应**GitHub**里的**Code**->**Local**->**HTTPS**，点击复制，然后粘贴到此处即可

   如果在网址后面添加新的字段，即可为仓库起一个新的名字，但是仓库内容完全一样

   ``` 
   git clone 网址 别名
   ```

3. 在本地完成修改操作

4. 将修改推送至远程仓库

   ```
   git push origin
   ```
